## 🚀 Featured Projects

### 1. DevFlow – Hiring & Assessment Platform

A full-stack recruitment platform with dedicated Candidate, Recruiter, and Admin dashboards.

- Developed job posting and application management workflows.
- Implemented JWT authentication and role-based access control.
- Integrated coding assessments and interview scheduling.
- Implemented real-time notifications using Socket.IO.

**Tech Stack:** React.js · Node.js · Express.js · MongoDB · JWT · Socket.IO

### 2. Informal Work-Zone Perception for Autonomous Vehicles

A research project focused on detecting unstructured road work zones for Connected and Autonomous Vehicles (CAVs).

- Developed a two-stage detection pipeline using YOLOv8x and YOLO-World.
- Identified significant detection challenges in linear road barriers.
- Observed 1% recall (1/96) for linear barriers versus 76% (29/38) for compact traffic-control devices.
- Proposed a four-stage perception architecture for improved work-zone understanding.

**Tech Stack:** Python · YOLOv8 · YOLO-World · Computer Vision

### 3. Keystroke Dynamics Authentication System

A behavioral biometric authentication system that enhances password-based login using individual typing patterns.

- Extracted dwell-time and flight-latency features.
- Used a Random Forest classifier for typing-pattern verification.
- Developed a desktop interface for authentication.

**Tech Stack:** Python · Scikit-Learn · NumPy · pynput · Tkinter

### 4. Responsive E-Commerce Storefront

A mobile-first clothing storefront with interactive product browsing.

- Created dynamic product listings.
- Implemented product filtering and interactive UI features.
- Designed a responsive interface for different screen sizes.

**Tech Stack:** JavaScript · HTML5 · CSS3
